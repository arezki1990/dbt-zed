zdbt

The dbt IDE, forged from Zed. Native Jinja-SQL, dbt LSP, instant query results, and an interactive column-level lineage canvas — no webviews, all GPUI.

A fork of Zed v1.17.2 · GPL-3.0 · macOS / Linux / Windows

Unsigned dev-channel builds — they install alongside official Zed and never auto-update over it. All builds on the releases page.

Everything dbt, inside the editor

Open a model and zdbt already knows your project: profiles, environment, lineage, and compiled SQL — with results one keystroke away.

⚡

Run a model with ⌘⏎

Execute the current model — or just the SQL you selected — through dbt show. Results land in a data grid with sorting, live search, a column picker, resizable columns, pinned row numbers, and CSV export.

🕸

Interactive lineage canvas

A React-Flow-style graph with layered auto-layout, materialization colors, per-node collapse handles, node drag, whole-graph pan, and semantic zoom. Click a column to light up its transformation path.

🧭

Browse-driven navigation

Opening any model recenters the lineage on it; clicking a node in the graph opens the file. The graph and the file tree are two views of the same project.

🧬

Jinja-aware dbt SQL

A native tree-sitter Jinja grammar with combined SQL injection — statements survive being interrupted by {{ ref(…) }}. Default for every .sql file, no configuration.

🛰

dbt language server

Prefers dbt Fusion's dbt lsp (go-to-definition, hover, completions, diagnostics) with a built-in workaround for its config-notification crash; falls back to the community Go LSP automatically.

🔩

Project automation

Finds nested dbt_project.yml files, in-repo profiles (local_profiles/, .dbt/), loads .env up to the repo root, and runs dbt parse + catalog builds on open. Eleven settings on a dedicated page.

Compiled SQL & column-level lineage

Flip the results panel to the compiled view to read the exact SQL dbt will run, syntax-highlighted and copyable. Or open the lineage view and trace one column from source to mart — ephemeral models included, with columns inferred from compiled select lists when the catalog can't see them.

Build from source

zdbt builds like Zed. You'll need Rust (rustup) and cmake; bring your own dbt (dbt Fusion recommended — it's never bundled).

# clone and build
git clone https://github.com/arezki1990/dbt-zed
cd dbt-zed
cargo build --release -p zed --features gpui_platform/runtime_shaders

# open your dbt project
./target/release/zed /path/to/your/dbt/project
